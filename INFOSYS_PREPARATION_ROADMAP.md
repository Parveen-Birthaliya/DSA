## 🔥 Problem-Solving Strategy for Coding Section

### **Time Management (45 mins for 2 problems):**
1. **First 2 mins:** Read both problems, choose easier one
2. **Next 18 mins:** Solve easier problem completely
3. **Next 20 mins:** Solve harder problem (aim for 70-80% cases)
4. **Last 5 mins:** Debug, test edge cases

### **Problem-Solving Template:**
```python
# Step 1: Understand problem (1 min)
# - Read twice, note constraints
# - Identify input/output format

# Step 2: Plan approach (2 mins)
# - Think of brute force first
# - Optimize using DS/Algo patterns

# Step 3: Code (10-12 mins)
# - Write clean, readable code
# - Handle edge cases

# Step 4: Test (2-3 mins)
# - Test with sample inputs
# - Check edge cases: empty, single element, negative numbers
```

### **Common Patterns to Remember:**
1. **Two Pointers:** Sorted array problems, palindromes
2. **Sliding Window:** Subarray/substring problems
3. **HashMap:** Frequency counting, finding pairs
4. **Stack:** Parentheses, next greater element
5. **BFS/DFS:** Tree/graph traversal
6. **DP:** Optimization problems with overlapping subproblems

## 📞 Quick Reference - Must-Know Before Exam

### **Time Complexities:**
- Linear Search: O(n)
- Binary Search: O(log n)
- Bubble/Insertion/Selection Sort: O(n²)
- Merge/Quick Sort: O(n log n)
- HashMap operations: O(1) average

### **Space Complexities:**
- Recursion: O(depth of recursion tree)
- DP with memoization: O(number of states)

### **Common Edge Cases:**
- Empty array/string: [], ""
- Single element: [1], "a"
- All same elements: [1,1,1,1]
- Negative numbers: [-1, -5, -3]
- Large numbers: 10^9
- Zeros: [0, 0, 0]
