### **Problem 1: Array Manipulation (20 minutes)**

**Title:** Find the Second Largest Element in Array

**Description:**
Given an array of integers, find the second largest element. If the second largest doesn't exist, return -1.

**Input Format:**
- First line: N (size of array)
- Second line: N space-separated integers

**Output Format:**
- Single integer (second largest element or -1)

**Constraints:**
- 1 ≤ N ≤ 10^5
- -10^9 ≤ arr[i] ≤ 10^9

**Examples:**

**Example 1:**
```
Input:
5
10 5 8 20 15

Output:
15
```

**Example 2:**
```
Input:
3
5 5 5

Output:
-1
```

**Example 3:**
```
Input:
2
10 20

Output:
10
```

**Problem 2 Solution (Python):**
```python
s = input()

# Keep only alphanumeric and convert to lowercase
cleaned = ''.join(c.lower() for c in s if c.isalnum())

# Check palindrome
if cleaned == cleaned[::-1]:
    print("YES")
else:
    print("NO")
```
